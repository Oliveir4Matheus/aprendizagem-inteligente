# Avaliações

Dois pareceres independentes sobre este sistema, escritos de lentes diferentes.
Abra os `.html` no navegador — são autocontidos, sem dependência externa.

| Arquivo | Lente | Pergunta que responde |
|---|---|---|
| [`qualidade-de-aprendizagem.html`](qualidade-de-aprendizagem.html) | Psicologia cognitiva da aprendizagem | Quando o aluno senta, o que acontece com a memória dele? |
| [`usabilidade.html`](usabilidade.html) | Usabilidade e abandono | Onde o aluno desiste ao longo da jornada? |

## Qualidade de aprendizagem — parecer principal

Avalia o sistema como **tutor**, contra a evidência empírica de retenção durável, por
uma rubrica de sete alavancas pontuadas de 0 a 5: recuperação ativa, prática espaçada,
intercalação, dificuldade desejável, calibração metacognitiva, carga cognitiva e
transferência. Também avalia o processo de configuração como instrumento diagnóstico.

**Cada afirmação traz a fonte e o grau de evidência** — `forte` (meta-análise ou ensaio
randomizado), `média` (estudos convergentes) ou `teórica` (inferência a partir de modelo
aceito, sem teste direto do caso). A terceira categoria existe porque avaliar
honestamente inclui dizer onde se está inferindo.

## Usabilidade

Avalia o sistema pelos **pontos de fuga** — os momentos em que o aluno escolhe entre
continuar e fechar. Vale a ressalva registrada no próprio parecer de aprendizagem: parte
dessa crítica cobra do sistema comportamentos de produto de engajamento, e **a
responsabilidade de aparecer para estudar é do aluno**. Um tutor não persegue ninguém.
Leia com esse desconto.

## Como atualizar

Os pareceres refletem um commit específico, citado no rodapé de cada um. Depois de
mudanças relevantes no método ou no protocolo, vale reemitir — a comparação entre
emissões diz mais do que o placar de uma delas isolada.
